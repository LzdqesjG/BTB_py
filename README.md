# Binary Tree Battle / 二叉树战斗

基于 Pygame 的双人对战策略游戏。通过构建二叉树扩张领地，用树枝切断对方节点，穿透对方根节点即可获胜。

## 游戏概览

- **红方** 根节点位于屏幕 **左上角**
- **蓝方** 根节点位于屏幕 **右下角**
- 双方初始点数：**10 点**
- 回合制，轮流操作
- 每个节点最多 **2 个子节点**（二叉树结构）
- 唯一胜利条件：**你创建的树枝穿过对方根节点**

***

## 核心玩法

### 1. 创建新节点

从己方节点按住鼠标拖出，在可用范围内释放即可创建新节点。新节点通过树枝与父节点相连。

### 2. 调节强度

| 操作           | 效果              |
| ------------ | --------------- |
| 拖拽时 **滚轮上**  | 新节点强度 +1（消耗 1 点） |
| 拖拽时 **滚轮下**  | 新节点强度 -1（最低 1）   |
| **右键** 己方树枝 | 进入树枝修改模式 |
| 修改模式中 **滚轮 / ↑↓** | 调整树枝强度（只能升级） |
| 修改模式中 **Enter / 右键** | 确认修改（消耗点数） |
| 修改模式中 **Esc** | 取消修改 |

强度范围：**1 \~ 5**

### 2.1 树枝修改模式

- 右键点击**己方**树枝进入修改界面，屏幕上会显示目标树枝高亮和强度面板
- **只能升级，不能降级**：调整范围是 `当前强度+1` ~ `5`，不会出现低于当前强度的选项
- 升级每级消耗 1 点，点数不足时无法再升
- 拖拽创建节点时滚轮只影响**新节点**强度，不会误调已有树枝

### 3. 选择创建范围

拖动过程中按 **空格键** 循环切换范围半径：

| 范围  | 消耗点数  | 半径  |
| --- | ----- | --- |
| 默认  | **0** | 120 |
| 1 级 | **1** | 160 |
| 2 级 | **2** | 200 |
| 3 级 | **3** | 240 |

范围越大消耗越多，但可以伸到更远的位置。

### 4. 结束回合

- 点击右下角 **"结束回合"** 按钮
- 或按 **Tab 键**

> 创建节点**不会**自动结束回合。你可以在创建节点后继续调节树枝强度，再手动结束回合。

### 5. 点数包

场上随机刷新金色点数包，节点碰到即可拾取：

| 颜色 | 点数 | 出现概率 |
| -- | -- | ---- |
| 金色 | +1 | 40%  |
| 橙色 | +2 | 30%  |
| 红橙 | +3 | 30%  |

吃掉后会在地图随机位置生成新的点数包，保持场上始终有 4 个。

## 操作指南

### 快捷键速查

| 操作      | 键位 / 方式        |
| ------- | -------------- |
| 创建节点    | 从己方节点拖拽鼠标，松开创建 |
| 调节新节点强度 | 拖拽中 **滚轮**     |
| 修改树枝强度  | **右键** 己方树枝 → 滚轮 / ↑↓ 调整 |
| 确认修改树枝 | **Enter** 或再次 **右键** |
| 取消修改树枝 | **Esc** |
| 切换创建范围  | 拖拽中 **空格**     |
| 自动吸附开关  | **B**（拖拽中鼠标超出范围圈时自动吸到边界） |
| 结束回合    | **Tab** 或点击按钮  |

### 界面提示

- **带脉冲光环的节点** = 本回合可操作（还能扩展子节点）
- **绿色提示文字** = 操作合法可执行
- **红色提示文字** = 点数不足或超出范围
- **蓝色虚线圈** = 当前选择的范围半径
- **悬停树枝高亮** = 可滚轮调节强度
- **拖拽实时预览** = 绿线可放置 / 红线不可放置 / 金线命中对方根节点（直接获胜）
- **红色光圈 + 叉号** = 预览中会被切断删除的对方节点
- **橙色光圈** = 预览中会被削弱但保留的对方节点
- **金色小圆点** = 自动吸附开启时，吸附到范围边界后的实际位置
- **树枝修改面板** = 右键树枝后显示，可调强度

## 联机对战

支持局域网对战（红方开房，蓝方加入）。

### 房主（红方）

1. 主菜单点击 **"创建房间 (红队)"**
2. 等待蓝方连接（底部显示连接状态）
3. 蓝方连接后点击 **"开始游戏"**

默认端口 `8447`，可在等待界面修改。

### 加入（蓝方）

1. 主菜单点击 **"加入房间 (蓝队)"**
2. 输入房主 IP 地址（如 `192.168.1.100`）
3. 也可指定端口：`192.168.1.100:8447`
4. 等待房主开始游戏

### 网络架构

- 红方为主机，承担所有游戏逻辑计算
- 蓝方为客户端，发送操作请求，接收状态同步
- 内置反作弊：服务端验证蓝方每一个操作是否合法

## AI 对战

主菜单选择 **"AI 对战"** 进入人机模式。系统随机分配队伍，你控制一方，AI 控制另一方。

### AI 策略

AI 使用多维度评分决策：

- **进攻**：向你的根节点方向推进节点，寻找能切断你树枝的路径
- **防守**：在你到 AI 根节点的路径上布置拦截节点
- **切割**：主动检测新树枝是否能穿透你的节点，穿过根节点直接判定胜利
- **资源**：间歇强化关键树枝强度，优先拾取附近的点数包
- **放置后强化**：放置节点后 AI 会优先加固威胁走廊内的低强度树枝（每回合最多 2 次）
- **记忆**：被摧毁的落点位置不再重复重建（"打地鼠"记忆）
- **随机性**：AI 聪明但可被击败，不会每步都完美

> 难度均衡设计：AI 有攻击性和防守意识，但通过加权随机选择保留不确定性。你有机会赢，但不能掉以轻心。

> **思考时间可配置**：AI 每回合的"思考"延迟在 `config.json` 的 `ai.think_delay_frames` 中调整（默认 90 帧 ≈ 1.5 秒）。

## 回放系统

每局游戏结束后自动保存回放文件（JSONL 格式），可在主菜单 **"回放"** 中观看。

### 回放控制

| 操作   | 快捷键 | 鼠标操作       | 说明       |
| ---- | --- | -------- | -------- |
| 播放/暂停 | 空格  | 点击"播放"按钮 | 自动逐步播放   |
| 上一步  | ←   | 点击"上一步"按钮 | 回退一个回合   |
| 下一步  | →   | 点击"下一步"按钮 | 前进一个回合   |
| 进入残局 | —   | 点击"进入游戏"按钮 | 从当前步骤开始残局对战 |
| 返回   | Esc | 点击"返回"按钮 | 回到回放文件列表 |

自动播放速度：约 1 秒/步，播到最后一步自动停止。

### 回放文件选择

支持键盘与鼠标混合操作：

- **单击** 一行 → 选中该回放
- **双击** 一行 → 直接开始播放
- **滚轮** / **↑↓** → 上下切换选中
- **Enter** → 开始播放
- **返回 / 删除** 按钮 → 鼠标点击操作；删除时再次点击"确认删除"移入 `replays/deleted/`

### 回放文件

- 保存路径：`replays/YYYYmmdd_HHMMss.bpr`
- JSONL 格式，每行一个操作记录，包含节点放置、树枝调节、切割、拾取等全部动作
- 联机/AI 模式同样录制
- 联机**蓝队（客户端）不保存回放**——回放由房主（服务端）权威记录，客户端不会生成空文件

## 点数与消耗

### 点数来源

| 来源    | 数量           |
| ----- | ------------ |
| 初始    | 10           |
| 点数包   | +1 / +2 / +3 |

> 注意：树枝强度**不能降级**，因此没有"降级返还点数"这一来源。

### 点数消耗

| 操作     | 消耗    |
| ------ | ----- |
| 强度 1   | 0     |
| 强度每 +1 | 1 点   |
| 范围 120 | 0     |
| 范围 160 | 1 点   |
| 范围 200 | 2 点   |
| 范围 240 | 3 点   |
| 树枝升级  | 1 点每级 |

> 总消耗 = 强度消耗 + 范围消耗。强度 3 + 范围 160 = (3-1) + 1 = 3 点。

## 碰撞与切割规则

### 新树枝穿过对方树枝

- 对方树枝的交点子节点 **强度 - 攻击方强度**
- 强度 ≤ 0 → 该子节点及其**所有后代全部删除**

### 新树枝穿过对方普通节点

- 该节点 **强度 - 攻击方强度**
- 强度 ≤ 0 → 该节点及其子树删除

### 新树枝穿过对方根节点

- **攻击方直接获胜！** 游戏结束。

> 同队之间不触发切割。切割只对敌队生效。

## 小技巧

- **强度 1 的节点不要太多**：虽然免费，但容易在切割战中一次被灭。至少 2 强度才有基本的生存能力。
- **点数包优先级高**：移动鼠标过去碰一下就能拿点数，不消耗回合。缺点了多捡。
- **范围圈可以卡位置**：不要总用最大的范围。小范围虽然近，但消耗 0 点，适合节约做关键推进。
- **树枝强度也要管**：高强度的树枝更难被切断，且敌方树枝穿过你时会遭到反噬（敌方树枝被你的强度削减）。
- **保护根节点**：尽量不要让根节点裸露在外。在根节点周围多建几个节点形成屏障。
- **右键调树枝强度**：创建节点后不急着结束回合，右键树枝进入修改模式升级强度，高强度的树枝等于一道防线。
- **树要散不要密**：如果节点挤在一起，对方一条强力树枝可能一次性穿透多个节点，全军覆没。
- **节奏控制**：每回合可以做：拖节点（1次）+ 升级树枝（多次）+ 捡点数包（自动），充分利用再结束回合。
- **点满 2 个子节点**：不要让节点空着子节点名额，等于浪费延伸潜力。
- **树枝只能升不能降**：升级前想清楚，一旦升级点数就花出去了，无法退还。

***

## 注意事项

- 创建节点后不能撤销，提前想好位置。
- 每个节点最多 2 个子节点，满了就不能再从该节点拖拽。
- 离开菜单界面时如有网络连接受损会自动断开。
- 联网时如果一方断线，双方都会退回菜单。
- 反作弊系统在服务端运行，蓝队提交非法操作会被拒绝并记录日志（包括尝试降级树枝）。
- 树枝强度**只能通过右键修改模式升级**，拖动创建节点时滚轮只影响新节点强度。
- 连线只能是跨队切割，不会误伤自己人。
- **己方回合开始时**会播放一段随机音调的音效提示。
- 联机蓝队不保存回放，回放文件由房主生成。

## 运行方式

### 依赖

- Python 3.9+
- Pygame 2.x

安装依赖：

```bash
pip install -r requirements.txt
```

### 启动

```bash
python main.py
```

### 按钮功能

| 按钮        | 模式    | 说明              |
| --------- | ----- | --------------- |
| **单人**    | 单人本地  | 自己控制红蓝双方轮流操作    |
| **AI 对战** | 人机对战  | 随机分配队伍，与 AI 对决  |

| **设置**    | —     | 预留，暂未开放         |
| **退出**    | —     | 退出游戏             |

## 配置文件

游戏基础参数可通过项目根目录的 `config.json` 调整（**AI 决策参数除外**，AI 参数见 `AI/ai.json`）：

| 分组 | 配置项 | 默认值 | 说明 |
|------|--------|--------|------|
| `display` | `width` / `height` | 1300 / 700 | 窗口尺寸 |
| `display` | `fps` | 60 | 帧率 |
| `gameplay` | `initial_points` | 10 | 初始点数 |
| `gameplay` | `min_strength` / `max_strength` | 1 / 5 | 强度范围 |
| `gameplay` | `max_children` | 2 | 每节点最大子节点数 |
| `ai` | `think_delay_frames` | 90 | AI 思考延迟（帧，60帧≈1秒） |
| `pickup` | `radius` / `min_root_distance` | 13 / 160 | 点数包尺寸与根节点最小距离 |
| `pickup` | `values` | [1, 2, 3] | 点数包分值列表 |
| `network` | `default_port` | 8447 | 联机默认端口 |

> 配置文件缺失时自动使用默认值。修改后重启游戏生效。

## 日志系统

每次启动游戏会在 `logs/` 目录生成一个日志文件：

- 文件名：`logs/YYYYmmdd_HHMMssa.log`（启动时间 + 后缀）
- 重名时后缀自动递增：`b`、`c`、`d`...
- 控制台同时输出简版格式 `[DEBUG] xxx`，文件内为完整格式 `[2026-08-10 13:28:44,872 DEBUG] xxx`
- 日志包含游戏运行状态、音效加载、AI 操作、网络消息等调试信息
