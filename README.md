# Binary Tree Battle / 二叉树战斗

基于 Pygame 的双人对战策略游戏。通过构建二叉树扩张领地，用树枝切断对方节点，穿透对方根节点即可获胜。

## 游戏概览

- **红方** 根节点位于屏幕 **左上角**
- **蓝方** 根节点位于屏幕 **右下角**
- 双方初始点数：**10 点**
- 回合制，轮流操作
- 每个节点最多 **2 个子节点**（二叉树结构）
- 唯一胜利条件：**你创建的树枝穿过对方根节点**

***

## 核心玩法

### 1. 创建新节点

从己方节点按住鼠标拖出，在可用范围内释放即可创建新节点。新节点通过树枝与父节点相连。

### 2. 调节强度

| 操作           | 效果              |
| ------------ | --------------- |
| 拖拽时 **滚轮上**  | 节点强度 +1（消耗 1 点） |
| 拖拽时 **滚轮下**  | 节点强度 -1（最低 1）   |
| 悬停树枝 **滚轮上** | 树枝强度 +1（消耗 1 点） |
| 悬停树枝 **滚轮下** | 树枝强度 -1，返还 1 点  |

强度范围：**1 \~ 5**

### 3. 选择创建范围

拖动过程中按 **空格键** 循环切换范围半径：

| 范围  | 消耗点数  | 半径  |
| --- | ----- | --- |
| 默认  | **0** | 120 |
| 1 级 | **1** | 160 |
| 2 级 | **2** | 200 |
| 3 级 | **3** | 240 |

范围越大消耗越多，但可以伸到更远的位置。

### 4. 结束回合

- 点击右下角 **"结束回合"** 按钮
- 或按 **Tab 键**

> 创建节点**不会**自动结束回合。你可以在创建节点后继续调节树枝强度，再手动结束回合。

### 5. 点数包

场上随机刷新金色点数包，节点碰到即可拾取：

| 颜色 | 点数 | 出现概率 |
| -- | -- | ---- |
| 金色 | +1 | 40%  |
| 橙色 | +2 | 30%  |
| 红橙 | +3 | 30%  |

吃掉后会在地图随机位置生成新的点数包，保持场上始终有 4 个。

## 操作指南

### 快捷键速查

| 操作      | 键位 / 方式        |
| ------- | -------------- |
| 创建节点    | 从己方节点拖拽鼠标，松开创建 |
| 调节新节点强度 | 拖拽中 **滚轮**     |
| 调节树枝强度  | 悬停己方树枝，**滚轮**  |
| 切换创建范围  | 拖拽中 **空格**     |
| 结束回合    | **Tab** 或点击按钮  |

### 界面提示

- **带脉冲光环的节点** = 本回合可操作（还能扩展子节点）
- **绿色提示文字** = 操作合法可执行
- **红色提示文字** = 点数不足或超出范围
- **蓝色虚线圈** = 当前选择的范围半径
- **悬停树枝高亮** = 可滚轮调节强度

## 联机对战

支持局域网对战（红方开房，蓝方加入）。

### 房主（红方）

1. 主菜单点击 **"创建房间 (红队)"**
2. 等待蓝方连接（底部显示连接状态）
3. 蓝方连接后点击 **"开始游戏"**

默认端口 `8447`，可在等待界面修改。

### 加入（蓝方）

1. 主菜单点击 **"加入房间 (蓝队)"**
2. 输入房主 IP 地址（如 `192.168.1.100`）
3. 也可指定端口：`192.168.1.100:8447`
4. 等待房主开始游戏

### 网络架构

- 红方为主机，承担所有游戏逻辑计算
- 蓝方为客户端，发送操作请求，接收状态同步
- 内置反作弊：服务端验证蓝方每一个操作是否合法

## 点数与消耗

### 点数来源

| 来源    | 数量           |
| ----- | ------------ |
| 初始    | 10           |
| 点数包   | +1 / +2 / +3 |
| 树枝降强度 | +1 每级        |

### 点数消耗

| 操作     | 消耗    |
| ------ | ----- |
| 强度 1   | 0     |
| 强度每 +1 | 1 点   |
| 范围 120 | 0     |
| 范围 160 | 1 点   |
| 范围 200 | 2 点   |
| 范围 240 | 3 点   |
| 树枝升强度  | 1 点每级 |

> 总消耗 = 强度消耗 + 范围消耗。强度 3 + 范围 160 = (3-1) + 1 = 3 点。

## 碰撞与切割规则

### 新树枝穿过对方树枝

- 对方树枝的交点子节点 **强度 - 攻击方强度**
- 强度 ≤ 0 → 该子节点及其**所有后代全部删除**

### 新树枝穿过对方普通节点

- 该节点 **强度 - 攻击方强度**
- 强度 ≤ 0 → 该节点及其子树删除

### 新树枝穿过对方根节点

- **攻击方直接获胜！** 游戏结束。

> 同队之间不触发切割。切割只对敌队生效。

## 小技巧

- **强度 1 的节点不要太多**：虽然免费，但容易在切割战中一次被灭。至少 2 强度才有基本的生存能力。
- **点数包优先级高**：移动鼠标过去碰一下就能拿点数，不消耗回合。缺点了多捡。
- **范围圈可以卡位置**：不要总用最大的范围。小范围虽然近，但消耗 0 点，适合节约做关键推进。
- **树枝强度也要管**：高强度的树枝更难被切断，且敌方树枝穿过你时会遭到反噬（敌方树枝被你的强度削减）。
- **保护根节点**：尽量不要让根节点裸露在外。在根节点周围多建几个节点形成屏障。
- **悬停树枝调强度**：创建节点后不急着结束回合，鼠标悬停在树枝上滚轮调强度，高强度的树枝等于一道防线。
- **树要散不要密**：如果节点挤在一起，对方一条强力树枝可能一次性穿透多个节点，全军覆没。
- **节奏控制**：每回合可以做：拖节点（1次）+ 调树枝强度（多次）+ 捡点数包（自动），充分利用再结束回合。
- **点满 2 个子节点**：不要让节点空着子节点名额，等于浪费延伸潜力。

***

## 注意事项

- 创建节点后不能撤销，提前想好位置。
- 每个节点最多 2 个子节点，满了就不能再从该节点拖拽。
- 离开菜单界面时如有网络连接受损会自动断开。
- 联网时如果一方断线，双方都会退回菜单。
- 反作弊系统在服务端运行，蓝队提交非法操作会被拒绝并记录日志。
- 树枝强度只能悬停调节，拖动创建节点时滚轮只影响新节点强度。
- 连线只能是跨队切割，不会误伤自己人。

## 运行方式

### 依赖

- Python 3.9+
- Pygame 2.x

安装依赖：

```bash
pip install pygame
```

### 启动

```bash
python main.py
```

### 按钮功能

| 按钮            | 模式    | 说明           |
| ------------- | ----- | ------------ |
| **开始游戏 (单人)** | 单人本地  | 自己控制红蓝双方轮流操作 |
| **创建房间 (红队)** | 联机房主  | 开房等待蓝方连接     |
| **加入房间 (蓝队)** | 联机客户端 | 输入房主 IP 加入游戏 |
